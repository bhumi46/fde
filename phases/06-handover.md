# Phase 6: Handover

**Goal:** Leave Acme able to run, fix and extend this without you.

## Tasks
1. Write `engagement/runbook.md` (SKILLS.md → Handover runbook).
2. Write a 10-minute demo script for Dana's quarterly review: problem → live demo → metric → next steps.
3. Write a final status update (SKILLS.md → Customer status update) with results against the success metric.
4. Ask someone else (or an AI agent with only the runbook) to start the service from scratch. Fix whatever they trip on.

## Concepts to learn

- Expectation management: be clear about what was *not* built and why.
